# Notes after the Meetup on 11 July 2026

On **11 July 2026** (morning, about 9am–12pm) I attended a meetup at the AWS Vietnam office — Bitexco. The session opened with an **AWS Q&A competition** between two teams, then moved on to **speaker talks**.

**Quick facts:** First Cloud Journey AI Meetup · Attendee · [Slides on Drive](https://drive.google.com/drive/folders/12m_o6omCCY0RDa4A0hRF0WK_ucFrUYxM)

### Opening — Cloud Architect: final match

The screen showed **Cloud Architect – Final Match**: team **KLKAT** vs **Ngũ Đại Hiệp**. It was an AWS knowledge quiz between two teams — more energetic than a talk-only meetup.

![Cloud Architect — Final Match](/images/4-EventParticipated/4.3-Event3/01-cloud-architect-final.png)

I learned that revising AWS is not only about labs: answering quickly in front of others revealed which topics I still found fuzzy and which ones I already knew well.

### Speakers after the contest

#### Ngô Lê Tấn Huy — Inside The Exam: AWS Cloud Practitioner

A strategic roadmap for the **AWS Cloud Practitioner** exam — not only listing domains, but how to study with a plan. Useful if I pursue a foundational certification later.

![Opening slide — Inside The Exam AWS Cloud Practitioner](/images/4-EventParticipated/4.3-Event3/cloud-practitioner-exam-slide1.png)

#### Thinh Nguyen — Securing Your Web Apps With AWS Security Agent

A DevSecOps angle: protecting web apps with **AWS Security Agent**. A reminder that security should not wait until features are done — it belongs early in the delivery process.

![Opening slide — AWS Security Agent](/images/4-EventParticipated/4.3-Event3/aws-security-agent-slide1.png)

#### Nguyễn Huỳnh Sơn — SLA and Monitoring

From **SLA** to monitoring what really matters. It helped me separate “having metrics” from “metrics that serve service commitments” — a habit for future operations work.

![Opening slide — SLA and Monitoring](/images/4-EventParticipated/4.3-Event3/sla-monitoring-slide1.png)

### What I took home

1. **AWS knowledge through competition** — questions stick better than passive listening.  
2. A clearer **Cloud Practitioner exam roadmap** as a learning frame.  
3. **Security + monitoring** as habits for real systems, not only for labs.  

Meetup 11/07 connected weekly labs to knowledge I can reuse later: certification prep, app security, and SLA-aware monitoring.
