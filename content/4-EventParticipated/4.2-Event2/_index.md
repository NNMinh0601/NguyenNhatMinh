# Notes after the Meetup on 6 June 2026

The **6 June 2026** meetup was mostly deep talks plus career stories. I attended at AWS Bitexco and tried to capture “key idea + what I will apply later” instead of copying slides.

**Quick facts:** First Cloud Journey AI Meetup · Attendee · [Slides on Drive](https://drive.google.com/drive/folders/1EgyIOIjUsgAMugJDcKKQy-AYbWkrHrLX)

### Each talk — in my own words

#### Bảo Huỳnh — Docker

Docker packages environments consistently. This talk helped me separate when **containers** matter versus when **functions** are enough — so I can choose the right deployment model in future projects.

![Opening slide — Bảo Huỳnh](/images/4-EventParticipated/4.2-Event2/bao-huynh-slide1.png)

#### Lê Hoàng Gia Đại — WAF + ML (NIDS)

About attack detection with WAF plus ML. I noted: static rules as a basic protection layer, ML as a smarter extension — useful later when building systems that need a front-door security layer.

![Opening slide — Lê Hoàng Gia Đại](/images/4-EventParticipated/4.2-Event2/le-hoang-gia-dai-slide1.png)

#### Nguyễn Quốc Bảo — Godot + AWS WebSockets

A realtime multiplayer case (Lambda, DynamoDB, WebSocket). I better understood why connect/disconnect/notify need separate handlers — a pattern I will meet again if I build notifications or realtime features later.

![Opening slide — Nguyễn Quốc Bảo](/images/4-EventParticipated/4.2-Event2/nguyen-quoc-bao-slide1.png)

#### Trương Phước — Effective Teamwork

A reminder that tech does not replace teamwork. Useful for any team project: clear ownership, shared updates, no working in silos.

![Opening slide — Trương Phước](/images/4-EventParticipated/4.2-Event2/truong-phuoc-slide1.png)

#### Việt Phát — GraphRAG (Neptune + Bedrock)

Graph-based RAG versus plain vector RAG. I noted it as a future direction if I go deeper on AWS AI blogs/agents.

![Opening slide — Việt Phát](/images/4-EventParticipated/4.2-Event2/viet-phat-slide1.png)

#### Vinh Trần — Helpdesk → Sysadmin → Cloud/DevOps

A stepwise self-learning career path. It helped me stay calm: I don’t need to jump straight to senior cloud — keep stacking labs and the next projects.

![Opening slide — Vinh Trần](/images/4-EventParticipated/4.2-Event2/vinh-tran-slide1.png)

### What I will do differently after the meetup

- On security learning: remember **WAF** as a baseline layer, and explore ML later if needed.  
- On architecture learning: quickly compare **Docker vs Lambda** on one small use case.  
- In teamwork: keep shared updates so we don’t work in silos.  

Meetup 06/06 did not replace weekly labs, but it connected labs to real problems and a clearer career direction — preparation for future projects.
